# 检测区间与复检

采样日期选择限量标准[start,end)，不使用报告出具日。同产品同残留项目在采样日须恰有一条有效标准，方法须在适用范围内。浓度统一mg/kg，ug/kg与ppb乘0.001，ppm等于mg/kg。检出限LOD必须大于0。

定量值以[value,value]记录，低于LOD的定量值拒绝。ND或<LOD以[0,LOD)记录，<后的数值必须等于报告LOD。区间上界≤限量为PASS，下界>限量为FAIL，其余UNCERTAIN。<0.01相对0.005限量为不确定，不能当零。

复检relation指向原报告，必须同样本、同批次、同产品、同残留项目、同方法、同采样日，报告日严格更晚。引用环、悬空引用与异样本引用隔离。每样本/项目只允许一个原始报告根。有效复检按reported、version取最新；并列结果矛盾拒绝。其他残留项目不因复检被覆盖。批次按FAIL>UNCERTAIN>PASS取最高风险等级。

## 批次归属与补录

一个样本只归属一个批次。补录（supplement）以独立CSV提交，在版本选择之前并入基础报告，因此补录改批不会被当成第二份样本结论。

- 原归属取基础报告中该样本最早的一份报告（reported、version、行号）。
- 补录行只要批次与原归属不同即为改批主张，即使其报告日更早也不作为原归属。主张须同产品、同采样日、报告日严格晚于原报告，且relation链完整（允许跨批次指向原批次的原始报告）。
- 最新有效主张的批次唯一时胜出，记为“补录改批”；并列最新主张指向不同批次时判为“归属冲突”，保留原归属并隔离全部主张，避免临近出证的旧批次被意外翻转。
- 已裁定新批次时，新批次中已明确重报的（产品,残留项目）在原批次的旧行标记为“被替代”，保留为采信证据但不再参与计算与判级；其余残留项目随样本迁入新批次。
- 被替代行不进入隔离清单，仍计入采纳（作为证据），通过归属台账与封存CSV的“归属”记录逐行可查；计算与判级只使用裁定批次中的代表报告。
- 无法裁定的主张按 `REFERENCE`（悬空/异样本/引用环）、`STALE`（报告日不晚于原报告）、`IDENTITY`（产品、采样日或批次缺失）、`CONFLICT`（并列冲突或基础报告自相矛盾）隔离。
- 补录与基础报告同号同版且内容一致视为重复，只计一次；同号同版内容不同则整次修订返回 `REVISION` 409，不覆盖既有证据。
- 修订以 `revision_of` 指向已归档的原批次；原批次记录不修改。同一基础输入与同一补录字节得到同一运行号，重跑不会重复增删样本。

## 通用采信约定

CSV按UTF-8 BOM、UTF-8、GB18030回退，保留逻辑记录结束行号；引号内换行由CSV解析。重复表头单独计数，列数不齐隔离。编码与ID按字符串保形。缺失哨兵为 `-`、`N/A`、`NULL`、`未知` 与空串；不得作为零。数值先NFKC归一、去千分位，再用Decimal。日期采用ISO；时间必须带偏移并转UTC。空文件、全空行、仅表头分别返回EMPTY_FILE、BLANK_FILE、HEADER_ONLY。

重复键为(id,version)，完全相同行去重；同键内容冲突则整组隔离，不取最后一行。行数对账：输入=采纳+隔离+空行+重复表头+完全重复。运行幂等键由输入字节、参数与规则版本计算。补录的行数、空行、重复表头与重复计数并入同一份对账。

同一报告ID的多个版本先选最高version，再构建复检引用链；历史版本留作采信证据，不重复参与最终项目判定。
